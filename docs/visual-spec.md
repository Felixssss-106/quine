# 视觉规格表 v0.1（骨架）
> 2026-09-16 · 基于「ChatGPT 式极简」参考集（refs/）+ 双面人设计语言
> 所有数值为**基准值**，实现期可微调；这是骨架，不是最终稿

## 0. 纪律（六条总原则）
1. 黑白灰是主角，颜色是客人：彩色只允许出现在 **链接 / 聚焦 / 危险** 三处
2. 无渐变、无重投影：层级靠留白、字重、毛发分隔线
3. 圆角即语言：按钮=药丸、卡片=16、抽屉=20 起
4. 动效服务「完整 / 优雅 / 流畅」，不是装饰
5. 双主题 = 镜像逻辑：浅色用「黑块」做反差，深色用「亮块」做反差；**两套都是亲儿子，没有主次**
6. 「神来之笔」全局限额 ≤2 处：agent 工作态字效 / 任务完成瞬间

## 1. 色板 Token

### 1.1 语义角色（两套主题同名）
| Token | 用途 |
|---|---|
| `ink` | 主角色：主按钮底 + 反色文字 / 主标题 |
| `bg` | 页面底 |
| `bgElevated` | 浮层与卡片面（毛玻璃底） |
| `fill` | 次级填充：用户气泡 / chip / 输入框底 |
| `line` | 毛发分隔线与描边（0.5–1pt） |
| `textPrimary` / `textSecondary` / `textTertiary` | 文字三级 |
| `accent` | 链接 / 聚焦 / 选中（系统蓝） |
| `danger` | 错误 / 危险（系统红） |

### 1.2 浅色（基准值）
- ink `#0D0D0D` · bg `#FFFFFF` · bgElevated `rgba(255,255,255,.72)+blur`
- fill `#F4F4F5` · line `#E8E8EA`
- text `#0D0D0D` / `#8A8A8E` / `#B0B0B5`
- accent `#007AFF` · danger `#FF3B30`

### 1.3 深色（基准值）
- ink **翻转**：主按钮 = 亮块（`#FFFFFF`）+ 黑字 —— 深色下的反差用亮块做
- bg `#000000` · bgElevated `rgba(28,28,30,.72)+blur`
- fill `#1C1C1E` · line `#2C2C2E`
- text `#FFFFFF` / `#98989E` / `#5A5A5F`
- accent `#0A84FF` · danger `#FF453A`

### 1.4 高光时刻
- **不引入新颜色**：完成/里程碑用「黑白反转块 + 动效」表达（比加颜色更克制）
- 参考图里的青绿 / 薰衣草紫属于「内容物料」（插画、订阅 pill），不进系统调色板

## 2. 字体系统
- 正文（UI）：系统字体先行（Roboto / 系统默认）；**中文字体配对后置**（MiSans / HarmonyOS Sans / 思源黑体，另做一轮小研究）
- 等宽：**Maple Mono** —— 代码 / 终端 / diff / 数据 / URL
- 数字：tabular（token 计数、耗时、版本号）
- 字号阶梯（基准）：
  - Display 36/44 Bold（首启大标题）
  - Title 24/32 Semibold（页面标题、空状态）
  - Headline 17/24 Semibold（按钮、列表主文案）
  - Body 17/26 Regular（对话正文）
  - Footnote 15/22 · Caption 13/18（来源、时间戳）
  - Mono：14/22（代码）· 13/20（终端流）· 12（数据标注）
- 中文纪律：字重降一档、行高 +2、全角标点、中英混排补 0.25em（盘古之白）

## 3. 形状与间距
- 圆角：pill=999（按钮/chips）· 卡片=16 · 大容器/抽屉顶=20 · 输入框=16 · 头像/logo=全圆
- 4pt 网格：页面边距 20 · 区块间距 24/32 · 列表行高 ≥56 · 按钮高 52–56 · composer 48–52 · 卡片内距 16–20 · chips 高 32–36

## 4. 组件清单 v0.1
**A 基础件**：主按钮（ink 药丸）· 次按钮（描边）· 文字按钮（accent）· chip · 开关 · 选择器 · 描边输入框（浮动标签，Compose 原生支持）· 分隔线 · 骨架屏（shimmer）· 空状态 · 呼吸点
**B 对话件**：消息列表（用户 = fill 气泡 20 圆角；AI = 裸文本平铺）· composer（＋ / 语音 / 发送 ink 圆钮）· 快捷 chips 行 · 来源 chips（favicon+小灰底）· 引用抽屉（带把手）· 上下文菜单（Copy / Edit）· 重试 & 编辑条 · 流式光标
**C 任务件（独有面）**：活动卡（标题+状态+进度点）· 任务卡 · **档位胶囊（保守/标准/狂奔 = 文字+圆点，不靠颜色）** · diff 视图（等宽+浅色高亮块）· 终端流（等宽+暗面）· 屏幕轨迹视图 · 图表卡（Vico）· 成本读数（tabular）
**D 浮层件**：底部抽屉 · popover（勾选列表）· 确认弹层（人话三段：做什么 · 影响 · 能否撤销）· toast · 内联错误（红描边+感叹号）· 分享卡
**E 神来之笔（限额 2）**：① agent 工作态字效（噪点/故障，小面积）② 任务完成收束动效（不超黑白）

## 5. 动效与触感（继承蓝图 v0）
- 时长 120 / 240 / 400ms；弹簧两套（标准 / 柔和）
- 关键模式：抽屉 = 弹簧上滑 · composer 展开 = 柔和 · 流式文本 = 匀速显现 + 光标 · 「Searching」= 呼吸点 1.2s 循环 · 完成 = 收束 400ms
- 触感：轻点 = light · 完成 = medium · 错误 = heavy×2 · 危险确认 = double tick
