# 安卓 Agent 工具 · v1 设计蓝图

> 版本 0.1（2026-09-15 · 六轮讨论定稿）
> 状态：方案讨论收官，未开始任何实现
> 关键词：纯本地 · 看得见它干活 · 双面人

## 0. 一句话定位

装进安卓手机的本地 agent 宿主——Codex / Claude Code 的移动版：改文件、搜网、操控系统、跑命令、做自动化。全部能力跑在设备上，只有模型推理出网。

## 1. 定位与原则

| 维度 | 决定 |
|---|---|
| 平台 | 安卓独占（手机 / 平板 / 折叠屏）——横竖屏适配是必需品 |
| 运行时 | 纯本地（沙箱、工具、文件全在设备；仅推理出网），架构预留混合可能 |
| 用户 | 极客 / 开发者优先；先自用跑顺，再外化 |
| 开源 | 开源，GitHub 首发（许可证待定） |
| 商业模式 | 后置（备选路径：开源核心 + 托管服务） |
| 差异化 | 护城河 = ①手机原生深度操控 + ③常驻自动化；②本地沙箱=基本功；④美术与体验=贯穿性验收标准（用户最重视） |
| 设计哲学 | 透明（看得见它干活）· 可控（分级信任）· 状态永不丢 |

## 2. v1 能力边界

### 2.1 文件
- 默认：SAF 用户授权目录（沙箱 + 授权范围）
- 进阶：Shizuku 全盘模式
- 红线：改动前自动快照 + 一键回滚

### 2.2 搜索与浏览器
- “眼睛”：多后端可插拔（免 key 通道兜底；可配 Tavily / Brave / Exa）+ 网页正文抓取
- “手”：内置可控 WebView（导航/点击/填表，登录态在 App 内）；明确不碰系统浏览器

### 2.3 系统操控（分层，按可用性升级）
- 标准 API 层：通知、剪贴板、日历、闹钟、媒体控制…
- Shizuku 层：应用管理（装 / 卸 / 冻结）、设置开关、force-stop、shell
- 无障碍层：读屏 + 模拟操作；第一条能力线 = 跨 App 自动化（自然语言探索式）
- v1 优先场景：a 设置开关 / c 应用管理 / d 跨 App 自动化

### 2.4 命令执行
- proot 自包含完整 Linux 沙箱（单发行版，开箱即用；不依赖 Termux）
- Root 增强（后置）：chroot 提速等

### 2.5 自动化
- 触发：定时（自然语言创建）+ 少量高价值事件（充电 / WiFi / 开机）
- 红线：前台服务常驻 + 电池白名单引导；失败必通知，绝不静默

### 2.6 附加能力
- 语音输入（v1）；图片 / 截图理解（v1 轻量版）
- 记忆：透明文件式（可看可编），跨会话
- 移动入口：分享进来（share sheet）+ 通知内快捷操作
- 扩展：内置原生工具 + MCP 兼容层；不做内置插件市场

### 2.7 v1 不做与后置
云同步 / 多设备 · 内置插件市场 · 多 agent 协作 · 桌面端 · iOS · 语音对话（双向）· 小组件（后置）· 快捷磁贴 / 锁屏（后置）· 折叠悬停 / 桌面窗口模式（后置）

## 3. 技术选型

| 模块 | 决定 |
|---|---|
| 客户端 | Kotlin + Jetpack Compose（单代码库） |
| 权限抽象 | 四档统一接口：标准 / Shizuku / Root（后置）/ 无障碍 |
| 沙箱 | proot 自包含 |
| 模型网关 | 自研：OpenAI 兼容主轴 + Anthropic / Gemini 原生适配 |
| Agent loop | 全自研（状态机 + 工具调用 + 流式渲染） |
| 扩展协议 | MCP（本地进程 / 远程 HTTP） |
| 记忆 | 文件式 + 会话持久化（为向量 / RAG 预留结构） |

## 4. 交互与信息架构

- **骨架**：双主面——聊天 / 任务平级；任务可独立诞生（定时、分享进来），结果双回（任务页 + 原会话）
- **透明**：分级折叠（进行中活动卡 → 结束折叠）+“安静 ↔ 啰嗦”滑杆
- **任务详情页五件套**：时间线 · diff · 终端流 · 网页轨迹 · 屏幕操作轨迹
- **信任**：三档 保守 / 标准 / 狂奔（全自动为可选最高档；默认仍拦最小危险集=删数据/花钱/发消息，设置内可关 + 红色警告）；确认弹层讲人话（要做什么 + 影响 + 可否撤销）
- **通知**：完成 / 失败 / 需确认 三节点 + 通知内操作；前台服务=低打扰“心跳条”
- **Onboarding**：渐进授权；首启仅两屏（模型 key + 沙箱初始化，带仪式感）

## 5. 美术与适配

- **气质**：双面人——**竖屏 = ChatGPT 式亲和对话面；横屏 = Codex 式工程台面**（“转个方向，从聊天切到工程台”）
- **主题**：跟随系统；深浅两套精做；深色=签名款；不另做配色变体
- **字体**：分层（正文 × 等宽 × tabular 数字）；默认留白好读 / 详情页信息密集；中文排版精调
- **动效**：轻拟人；完整 / 优雅 / 流畅；声音默认关
- **适配**：竖屏单栏 → 横屏双栏 → 平板折叠三栏；面板可用户自由收展；红线：状态永不丢、单手可达
- **资源选型（2026-09-15 定）**：设计系统=**Material 3 Expressive** 打底 + 自研「双面人」token 层（不引第三方设计系统）；动效=**Compose 原生 API（统一弹簧/时长 token，主力）** + **material-motion-compose**（转场三件套）+ **Rive**（人格化状态机：呼吸/工作/完成/错误）+ **compose-shimmer**（骨架屏）；Lottie 降级为素材补充。弃用：Konfetti（审美风险）、koreography、compottie、Orbit/quack-quack。
- **场景库**：sora-editor（编辑/diff）· multiplatform-markdown-renderer（消息）· Vico（图表）· Reorderable（拖拽）· Balloon（气泡）· Haze（毛玻璃，限浮层/栏位，节制）。
- **字体/图标**：等宽=**Maple Mono**（中文+连字）；正文=系统字体先行（中文字体配对后置）；图标=**Lucide** 为主 + Material Symbols 补系统图标。
- **动效 token 草稿 v0**：时长三档（微交互 ~120ms / 标准 ~240ms / 大转场 ~400ms）；弹簧两套（标准/柔和）；原则=无跳变 · 克制强调（仅完成/错误允许"神来之笔"）· 尊重系统"移除动画"开关 · 120Hz 适配；触感统一 haptics token（点击/完成/错误）。
- **审美校准 v1.1（2026-09-16，基于用户 50 张参考图）**：浅色极简为底、纯黑为主角（黑药丸 CTA / 黑色圆点 logo）；彩色极度克制（系统蓝=链接/聚焦）；大标题排版主视觉；全圆角（药丸/卡片/抽屉/描边+浮动标签输入框）；克制气泡（用户=灰气泡 / AI=裸文本）+ 来源 chips；毛玻璃浮层；状态可见（呼吸点 / 黑点 AI 化身 / citation 抽屉）；"神来之笔"=排版级字效（噪点/故障，限量 1-2 处）。**主题定案（2026-09-16）：跟随系统，深浅两套均精做（无主次；深色=浅色语言的镜像）；主色=系统蓝+黑，高光=黑白反转块+动效，不引入新颜色**。参考图存 refs/；《视觉规格表 v0.1》→ visual-spec.md；《动效规格表 v0.1》→ motion-spec.md（关键转场逐条 + 无跳变表 + Compose 实现映射）；《重点页面规格 v0.1》→ page-specs.md（首启两屏 / 任务详情页 / composer）。

## 6. 里程碑（垂直切片 · 业余节奏）

> 原则：每个里程碑 = 一个“能在手机上干成一件真事”的闭环；不设死线，按“能发 demo 的节点”推进。

- **M0 骨架**：聊天 + 工具调用打通（最小 loop）
- **M1 底座**：沙箱 + 文件（快照/回滚）+ 命令执行 + 双主面 + diff/终端 →“手机上的 Codex lite”
- **M2 代理 A**：搜索 / 抓取 + WebView 操控 + 通知体系
- **M3 代理 B**：Shizuku 系统操控 + 定时自动化
- **M4 冲刺**：无障碍跨 App 自动化（探索式 + 屏幕轨迹）+ 语音 + 视觉
- **M5 打磨与发布**：美术精修 / 深浅主题 / 动效 / 性能 / 开源发布

纪律：功能开关 · 失败可见 · 每阶段后砍一轮

## 7. 风险与对策

重点（用户前三）：①②④ ｜ 看板（持续盯）：③⑤

1. **后台存活** → 前台服务 + 电池白名单引导 + watchdog + 失败必通知 + 任务队列持久化
2. **无障碍合规** → 默认关、按需开启、用途明示；GitHub / 酷安优先分发，Play 后置评估
3. **范围失控** → 三档落地序 + 功能开关 + 定期砍
4. **GUI 探索成功率** → 全程可见 + 随时接管 + 重试预算 + 录制通道备用
5. **成本观感** → 任务页成本可见（token / ¥）+ 预算告警
