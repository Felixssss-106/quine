# 重点页面规格 v0.1（首启 / 任务详情 / composer）
> 2026-09-16 · 文字规格：结构 + 文案 + 状态 + 动效引用 · 基准值
> 配套：visual-spec.md（视觉）· motion-spec.md（动效）

## 0. 文案基调（全局）
- 人话、短句、克制；不卖萌、不谄媚、不堆感叹号
- **每个错误文案必须带"下一步动作"**（重试 / 去哪改 / 怎么检查）
- 称呼用「你」；自称尽量少（工具感 > 员工感）
- 术语不硬翻译：沙箱、diff、token 直接说

## 1. 首启（两屏）

### 屏幕一：欢迎 + 接模型
结构（上→下）：
1. 大标题 Display 36：**「你好。」**（留白要大）
2. 副文案（Body / textSecondary）：「我住在你的手机里：改文件、搜资料、跑命令、做自动化。**文件不出这台设备。**」
3. 模型接入区：
   - 说明行：「先接上你的模型」+ 小字「支持 OpenAI 兼容 / Anthropic / Gemini」
   - 供应商 chips 行（选中 = ink 底反白）
   - 描边输入框（浮动标签）：「粘贴 API Key」
   - 弱链接：「怎么拿 Key？」
   - 隐私小字（Caption / textTertiary）：「Key 只存本机（加密），不经过我们的服务器。」
4. 主按钮（黑药丸）：「继续」
5. 弱链接（后置彩蛋）：「先随便逛逛（功能受限）」
状态：
- Key 检测中：字段尾部 spinner → ✓（light 触感）/ 失败 = 红描边 + 抖动 + 「Key 好像不对，再检查一下？」
- Key 有效前「继续」保持禁用（灰）
动效：motion §2.9（标题逐行上浮，stagger 60ms；入场完成后输入框才可聚焦）

### 屏幕二：沙箱初始化（仪式感）
结构：
1. 大标题：「搭建你的本地工作间。」
2. 步骤列表（状态点 + 文案，完成 = 灰→黑）：
   ① 检查设备环境　② 展开 Linux 工作区　③ 初始化文件系统　④ 工具链自检
3. 等宽日志区（Mono 12 / 低对比 / 缓缓滚出 40 字/秒）：「[ok] mounting rootfs…」等真实日志，可折叠
4. 进度条：2pt 细条（确定进度）
5. 底部小字：「首次约 1–3 分钟，之后秒开。占用约 200 MB。」
状态：
- 失败：进度条停住转 danger → 「卡在第 ③ 步：存储空间不足。」+ 按钮「重试」「清理空间」；日志区自动展开
- 切后台：状态保持；通知"心跳条"显示进度
动效：完成 → 整屏黑白反转 120ms → 进入主界面（motion §2.9）

## 2. 任务详情页（五件套）

**核心决策：不用五个 tab —— 以"单一时间线"为骨，五件套作为内联附件块**（看得见干活 = 按时间顺序透明）。顶部过滤 chips 只做折叠，不动布局。

结构（上→下）：
1. **任务头卡**：任务名 + 状态胶囊（运行中=呼吸点 / 完成 / 失败 / 需确认）+ 读数行（耗时 00:42 · token 12.4k · ¥0.36，tabular）
   - 弱信息行：「来自会话《帮我整理周报》」·「用了：Shizuku ×2」·「档位：标准」
2. **过滤 chips 行**：全部 / 文件 / 终端 / 网页 / 屏幕
3. **时间线（主体，信息密集模式）**：
   - 条目解剖：时间戳（Caption 灰）· 状态点 · **人话标题**（Headline 17）· 摘要一行（灰）· 附件块（默认折叠）
   - 人话标题示例：「改了 3 个文件」/「跑了 npm test」/「看了 2 个网页」/「替你在设置里关了勿扰」——**不许术语裸奔**
   - 附件块形态（五件套）：
     a) **diff 块**：等宽；新增 = 「+」+ 极浅 ink 底；删除 = 「−」+ 灰字删除线；**不用红绿**（黑白纪律；实测观感差再议）
     b) **终端块**：等宽 + **永久暗面**（无论主题都深色，终端的仪式感）；右上「全屏」；默认滚到尾部
     c) **网页块**：favicon + 标题 + 域名 + 抓取时间；点开 = 抽屉阅读视图
     d) **屏幕块**：关键帧缩略图横排 + 每帧动作说明（点/滑/输入）；点开 = 回放
   - 运行时末条 = 活动卡（呼吸点+当前动作）的"全量版"
4. **产物区**（完成态）：标题「这次留下了什么」：文件列表（名称+大小+时间）+「全部导出 / 分享」
5. **操作条（粘底）**：
   - 运行中：「停止」（描边）+「去聊天里看看」（文字）
   - 需确认：「批准」（ink）+「拒绝」+ 一行"要做什么+影响"摘要
   - 失败：「重试」（ink）+「接管」（文字，跳沙箱终端）
   - 完成：「再做一次」（描边）+「分享结果」（文字）
状态与边界：
- 长任务：每 20 条折叠一组「…还有 36 条」
- 「安静 ↔ 啰嗦」滑杆：控制条目默认展开程度
- 未开始：一句「排队等待中」+ 取消

## 3. composer（输入栏）

结构（下→上）：
1. **模式行**（框内顶部）：档位胶囊（保守/标准/狂奔，常驻）+ 模式 chips（「搜索」「只读」「沙箱」等，可 ×）
2. 输入框（fill 底 / 圆角 16 / Body 17）：
   - 空态占位：「让它干点什么…」
   - 聚焦后：「描述任务、粘贴东西、说要改哪个文件」
3. 按钮：
   - 左「＋」菜单：文件 / 图片 / 语音 / 「从别的 App 分享进来」说明
   - **右黑圆钮三态**：空 = 语音（按住说话）· 有字 = ↑ 发送 · 生成中 = ▪ 停止
4. 附件预览行（有附件时）：缩略 + 可删
交互规格：
- 多行：1→6 行（超出内滚）；高度柔和弹簧 240ms
- 语音：按住 = 波形条 + 「松开发送 · 上滑取消」；实时转写上屏（80ms/块）；进入/停止各 light 触感
- 发送：首次"飞入"列表（320ms），连发淡入；发送后立即复位不失焦
- 生成中仍可输入：下一条显示「排队中 · 1 条」
- **长任务出口**：生成超 ~2 分钟时，浮出提示条「要转成后台任务吗？」→ 一键转任务（与任务系统联动）
- 横屏：composer 固定聊天栏底部；竖屏：跟随键盘；底部安全区 +20（单手可达）
- 键盘：上滑收起（系统行为）；发送后键盘保持

## 4. 设置 · 应用图标（2026-09-17 新增）

- 位置：设置 → 外观 →「应用图标」
- 选项：**浅色**（白底 `>_`）/ **深色**（黑底 `>_`）单选；默认浅色；选中态 = ink 勾
- 小字说明：「切换后桌面图标会变化，个别机型需等几秒」
- 交互：点选即生效；120ms 选中动画 + light 触感；切换可能回到桌面（系统行为，事先说明）
- 实现注：`activity-alias` 双启动入口 + `setComponentEnabledSetting`（详见 icons/pixel-final/README.md）
