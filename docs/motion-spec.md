# 动效规格表 v0.1
> 2026-09-16 · 继承《视觉规格表 v0.1》与蓝图动效 token · 基准值可微调
> 目标：把「完整 / 优雅 / 流畅」变成逐条可执行的规格

## 0. 总纪律
- **完整**：每个状态切换必须有对应动画（见 §3 无跳变表）
- **优雅**：全局只有两套弹簧、三档时长；不逐处调参；动画永远不抢内容
- **流畅**：目标 60/120Hz 不掉帧；转场无白闪；列表动画不触发大重组
- **降级**：尊重系统「移除动画」——位移/缩放替换为 ≤120ms 交叉淡化
- **触感**：动画的"回声"，与动效同拍（§1.3）

## 1. 令牌

### 1.1 时长
| 档 | 值 | 用于 |
|---|---|---|
| 微 120ms | 按压、chip、开关、图标变换 |
| 标准 240ms | 抽屉、页面切换、卡片展开收起、消息进入 |
| 大 400ms | 双面切换、容器变换、完成收束、首启仪式 |

### 1.2 弹簧（全局唯二）
| 名 | 手感 | 参数基准 | 用于 |
|---|---|---|---|
| 标准 | 利落收口 | damping 0.85 / stiffness 380 | 导航、抽屉、按钮 |
| 柔和 | 呼吸落座 | damping 0.95 / stiffness 200 | 大容器、卡片、流式光标 |

位移类走弹簧；纯淡入淡出走 240ms 标准缓动。每个弹簧动画有"落定时间"基准（标准≈240ms、柔和≈400ms）。

### 1.3 触感
轻点 = light · 发消息 = light · 完成 = medium · 错误 = heavy×2（短促双震）· 危险确认 = double tick

## 2. 关键转场明细（逐条）

### 2.1 任务卡展开 / 收起（聊天内活动卡）
- 触发：点卡片
- 展开：容器高度 = 柔和弹簧（≈400ms）；内容行交叉淡入 + 上浮 8px，**stagger 20ms/行**；触感 light
- 收起：标准弹簧（≈240ms），**无 stagger**（收起不许拖沓）
- 边界：展开中再点 = 立即反向（不排队）；就地展开，不推走相邻项（滚动位置保持）

### 2.2 竖屏 ⇄ 横屏「变脸」（双面切换）★ 产品签名动作
- 触发：旋转 / 折叠开合 / 自由窗口拉伸
- 行为：container transform（≈400ms，标准弹簧）——
  1. 聊天列平滑迁移为左栏（宽度动画）
  2. 工作区（终端/文件面板）从右滑入（位移+淡入，尾部柔和）
  3. composer 从底部满宽迁移到聊天栏底部（尺寸+位置连续）
  4. 顶栏标题交叉淡化（180ms）
- 红线：**状态永不丢**——滚动位置、输入草稿、选中项原样保留
- 降级：240ms 交叉淡化 + 布局瞬时重排
- 备注：全站唯一"炫技位"；除它之外不再有第二个大型转场

### 2.3 完成收束（任务完成瞬间）★ 神来之笔 ②
- 行为：活动卡柔和弹簧收束为摘要卡（≈400ms）；进度点汇拢成单点 → 状态块**黑白反转**（ink 块 120ms）→ 回落为"完成"字样；触感 medium
- 克制：无彩带、无音效、无全屏动画；全站唯一一次"反转高光"

### 2.4 错误回弹
- 输入类：红描边 + 水平轻抖（±6px ×3，320ms）+ heavy×2；错误文案 120ms 淡入
- 任务类：失败卡描边转 danger（120ms）→ 缓慢退场（不抖大卡）；重试按钮上浮 8px 进入（240ms）；heavy×2

### 2.5 抽屉（底部 sheet）
- 打开：标准弹簧（≈400ms）；scrim 淡入 240ms；毛玻璃 blur 于开启后 120ms 渐入
- 拖拽：1:1 跟手；松手按速度决定归位/关闭（阈值 ≈400px/s）
- 关闭：240ms；从抽屉内推入新页 = 抽屉沉底 60% 淡入（layered push）

### 2.6 composer（输入栏）
- 展开多行：高度柔和弹簧 240ms；发送钮"点→箭头"crossfade 120ms
- 语音长按：composer 收拢为波形条（240ms）；松手发送 / 上滑 96px 取消（波形去色）；进入/停止各 light
- 模式 chips（档位类）：自 composer 上方顶出（上浮 8px，stagger 20ms）；选中 = 120ms 底色填充 + light tick
- 发送消息：气泡从 composer"飞入"列表（320ms）——**仅首次发送执行**，连续发送直接淡入（防疲劳）

### 2.7 导航
- 列表 → 详情：**卡片长大成页面**（container transform 400ms）；返回反向 320ms
- 平级切换（聊天 ⇄ 任务）：shared axis X 240ms + 标签指示器滑动 120ms
- popover 菜单：origin 缩放 0.96→1 + 淡入（120ms）

### 2.8 流式与状态件
- AI 流式文本：按块显现（80ms/块，无打字机抖动）；光标 = 1s 呼吸块
- 「Searching…」呼吸点：1.2s 循环（透明度 .35↔1，缩放 .92↔1）
- 骨架屏 shimmer：1.6s 扫过循环（低对比；深色再降一档）
- 不确定进度条：2pt 细条，1.6s 扫动
- 档位胶囊：圆点位移 120ms + 文字 crossfade；**不换色**

### 2.9 首启仪式（两屏）
- 标题逐行上浮（+8px 淡入，320ms，stagger 60ms）；图标行顺次进入（stagger 40ms）
- 沙箱初始化：细进度条 + 等宽日志缓滚（≈40 字/秒，不抢戏）
- 完成：整屏黑白反转 120ms → 回正 → 进入主界面（400ms）

### 2.10 列表
- 新消息/新任务：底部淡入上移 8px（240ms）
- 增删：高度+位移动画（240ms），stagger 上限 5 项（再多则批量）
- 删除：高度收拢 240ms + 行淡出；**不**做整列表抖动

## 3. 无跳变表（"完整"验收清单）
| 场景 | 必须有动画 |
|---|---|
| 发送/接收消息 | ✓ |
| 任务四态互转（开始/进行/完成/失败） | ✓ |
| 档位切换、面板开合 | ✓ |
| 竖⇄横、折叠开合 | ✓ |
| 页面进出、抽屉、popover | ✓ |
| 错误出现/消失 | ✓ |
| 空状态 ⇄ 有内容 | ✓ |
| 流式开始/结束（光标换出） | ✓ |

## 4. 实现映射（Compose 速查）
| 模式 | API |
|---|---|
| 尺寸/高度动画 | `animateContentSize` + 柔和弹簧 |
| 出现消失 | `AnimatedVisibility` |
| 连续值驱动 | `updateTransition` |
| 页面/卡片变换 | `SharedTransitionLayout` + `lookahead` |
| 列表项动画 | `LazyItemScope.animateItem` |
| 弹簧 | `spring(dampingRatio, stiffness)` |
| 呼吸/循环 | `rememberInfiniteTransition` |
| 字效（神来之笔 ①） | AGSL shader 或 Rive |
| 完成收束（②） | Rive 状态机（备用：纯 Compose） |

## 5. 验收
- 中端机连续使用无动效掉帧记录
- 全站弹簧 = 2 套；时长 = 3 档（代码审查项）
- 每处动画都有 reduced-motion 降级分支
