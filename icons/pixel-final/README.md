# Quine 图标资产 · pixel-final（2026-09-17 定稿）

> 造型：16×16 像素网格的终端提示符「>_」｜`>` = 墨黑 / 纯白，`_` = 矢车菊蓝 `#6495ED`
> 浅色版：白底 `#FFFFFF` ｜ 深色版：黑底 `#0D0D0D`
> 两种版本在 App「设置 → 外观 → 应用图标」由用户自行切换

## 文件清单
- `icon_light_1024 / 512 / 192 / 144 / 96 / 72 / 48.png` —— 浅色（白底）
- `icon_dark_…` —— 深色（黑底），同尺寸组
- `fg_light_432.png` / `fg_dark_432.png` —— Android 自适应图标·前景层（108dp@4x；内容居中，约占安全区 54%）
- `mono_432.png` —— Android 13+ 主题图标·单色层
- 自适应背景层：浅色版 = `#FFFFFF`；深色版 = `#0D0D0D`

## 尺寸对照
mdpi 48 / hdpi 72 / xhdpi 96 / xxhdpi 144 / xxxhdpi 192；商店 512
（72 与 48 由 144/96 整数半缩，保持像素绝对锐利）

## 设置内切换（工程注）
- 实现：两个 `activity-alias` 启动入口（浅色图标 / 深色图标），运行时用
  `PackageManager.setComponentEnabledSetting()` 切换；切换后个别启动器需数秒刷新
- UI：设置 → 外观 →「应用图标」，单选 + 勾选态；小字提示「切换后桌面图标会变化，个别机型稍等几秒」；切换动作给 light 触感
- 注意：切换时系统可能结束当前任务回到桌面，属正常现象
